Executive summary

A production system, not a one-off prompt

The playbook separates facts, strategy, creative generation, platform adaptation, and QA into explicit contracts so campaigns can scale without sacrificing brand or factual integrity.

The selected use case is conversion-oriented seasonal hospitality advertising: a high-value category where fresh creative is needed across destinations, audiences, seasons, platforms, and languages. The workflow converts one validated campaign into multiple testable directions while protecting Vinpearl’s premium positioning.

Why this use case

Hospitality acquisition demands both emotional appeal and precise operational facts. A reusable PAM workflow reduces time-to-market, increases A/B testing capacity, supports booking and occupancy goals, and keeps execution consistent across channels.

Source precedence

Campaign Brief → @Brand Guidelines → Verified Campaign Information → @Brand Assets → @Artifacts → @Connectors → Platform Requirements → Creative Optimization → Internal Reasoning.

Input schema

Structured, verified, campaign-specific

Creative generation starts only after all mandatory fields pass validation. Missing facts are never fabricated.

01Campaign

Name, objective, period

  • Unique human-readable name
  • Exactly one primary objective
  • Valid start and end dates
02Audience

Primary and secondary

  • One validated primary segment
  • Optional non-conflicting segments
  • Motivation, style, benefit priorities
03Promotion

Type, offer, window

  • Verifiable offer is mandatory
  • Supported promotion type
  • Booking window within period
04Destination

Destination and property

  • Verified destination required
  • Optional property must belong
  • Stop on invalid information
05Platform

Channel and placement

  • Facebook and Instagram
  • Google or Responsive Display
  • Discovery, Landing Hero, OTA
06Creative

Objective and constraints

  • Acquisition, conversion, retargeting
  • Optional emotional theme
  • Character and wording limits
07Brand

Guidelines and assets

  • @Brand Guidelines recommended
  • @Brand Assets optional
  • References must resolve
08Localization

Language and locale

  • Supported language required
  • Locale supports adaptation
  • Preserve meaning, not literal wording
09References

Artifacts and connectors

  • Reuse approved @Artifacts
  • @Connectors for verified facts only
  • Never override higher-priority data

Persistence rule

Only QA-approved outputs are promoted to reusable @Artifacts, with campaign identifier, timestamp, language, destination, audience, platform, version, and approval status.

QA framework

Creativity never overrides correctness

Eleven categories are scored from 0–5 and normalized to 100. Factual accuracy, brand integrity, and data integrity carry the greatest weight.

Weighted categories
Brand Consistency15%
Offer Accuracy15%
Destination Accuracy10%
Grammar5%
Readability10%
Audience Alignment10%
Platform Compliance10%
CTA Effectiveness5%
Creative Diversity10%
Visual Consistency5%
Data Integrity15%
Release thresholds
PASS

No factual errors, brand violations, or unresolved findings.

≥ 90
REVIEW

Minor quality issues; revise and rerun QA.

75–89
FAIL

Critical issue, contradiction, or brand violation.

< 75
Critical failure checklist
  • No invented offer, pricing, package, or booking period
  • No incorrect destination or property
  • No fabricated facts, statistics, reviews, awards, or claims
  • No deceptive urgency, guarantees, or prohibited language
  • No missing mandatory output sections
Controlled recovery
  • Retry only the earliest affected stage
  • Maximum three automatic retries
  • Escalate unresolved brand, campaign, legal, or creative issues
  • Human approval remains mandatory before publication
  • A failed quality gate blocks all downstream gates

Key features

Designed for reuse without creative drift

Modular contracts allow the same core system to flex across campaigns while stable controls protect the facts and the brand.

Portable across contexts

Reusable across campaigns, destinations, audiences, seasons, platforms, and languages.

Fact and brand guarded

Verified data and brand sources outrank creative reasoning and platform optimization.

Modular contracts

Skill, SOP, input, output, QA, and brand documents can evolve independently.

Built for testing

Variations differ by communication strategy, audience motivation, emotional angle, and composition.

Localized retries

Quality issues rerun only the earliest affected stage, up to three times, preserving efficient work.

Traceable outputs

Stable IDs, metadata, rationale, and QA findings support review and reusable artifact storage.
